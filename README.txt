SHYAM OTP WORKS — Front-end demo

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser.

This is a local front-end prototype only. It generates fictional random six-digit
sample codes in the browser. It does not provide phone numbers, receive SMS,
connect to WhatsApp/Telegram, verify external accounts, or process payments.
All displayed prices are illustrative UI labels, not offers for real OTP services.
